# Archive

The complete pre-restructure repository (~88 files, organically grown over ~10 months) is preserved on a dedicated branch and tag.

## Retrieve the original

```bash
# View on GitHub
open https://github.com/SunrisesIllNeverSee/MOS2ES/tree/archive/v1-original

# Clone the archived state locally
git clone https://github.com/SunrisesIllNeverSee/MOS2ES.git
cd MOS2ES
git checkout archive/v1-original

# Or check out by tag
git checkout v1.0-archive
```

## What's there

The archive branch contains every file from the chronologically-organized v1 layout, including:

- `I._MO§ES™/` — original Roots/Backend/Frontend/Problems/Stress-Testing structure
- `II._Signal Vault/` — original Seeds (S-0000 through S-0037), Artifacts, Codex Fragments
- `III._Vaultline/` — original Cloud Paradox + Exponential Data Growth
- `IV._Inquiry/` — original Investors / Collaboration / IP Filings
- `V._Medium_Articles/` — drafts and prep materials (most are duplicates of Seeds; not promoted to the v2 layout)
- `VI._Patent_Viability/` — original 4-phase viability assessment
- `Xiii_Latent_Image/` — original binary visualizations
- `grokdemo/` — original Grok thread including the predecessor extraction files (`raw.md`, `raw responses.md`, `GROK_THREAD_FULL_RECORD.md`, `CAPTURE_INSTRUCTIONS.md`)
