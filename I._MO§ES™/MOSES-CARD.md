## Runtime Ontology

`System → Agent → Persona → Role → Slot → Mission → Action → GovernanceState → Envelope → Operator`

A System powers an Agent. The Agent presents as a Persona. The Agent fills a Slot in a Mission. The Agent performs Actions. GovernanceState evaluates every Action against the Six Fold Flame. An Envelope records every Action as a signed, audited proof object. An Operator grants authority over the entire chain.

### Surfaced Definitions

- `Agent`: A durable, registered actor — the unit that can register, authenticate, fill slots, earn reputation, be governed, and be decommissioned. Not the System (LLM provider), not the Persona (presentation layer).
- `Envelope`: The signed, audited record of an Action — seed (DOI + content hash + lineage) + audit event (hash chain). The proof object. If governance is constitutional, the Envelope is what makes it enforceable after the fact.
- `GovernanceState`: The active constitutional constraint set that evaluates every Action. The Six Fold Flame made executable. Not advisory — blocking.
