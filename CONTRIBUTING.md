# Contributing

This repository is a **constitutional archive**, not a software project. The "code" here is markdown — every document is part of an interlocking lineage.

## What this means in practice

- **Read before opening issues.** The [`README.md`](./README.md) reading order is the fastest path. If your question is "what is MO§ES?" it's probably already answered in [`01_codex/`](./01_codex/) or [`02_constitution/`](./02_constitution/).
- **Direct external contributions are not accepted on the main branch.** This is a single-author archive (Deric J. McHenry / Ello Cello LLC) covered by a proprietary license. See [`LICENSE.md`](./LICENSE.md).
- **Citations are welcome.** If you reference MO§ES™ in academic, technical, or popular writing, link to the Codex ([`01_codex/CODEX.md`](./01_codex/CODEX.md)) and credit Ello Cello LLC.
- **Lineage is the spec.** Every file traces back to the origin-cycle filing. Forks that strip attribution are expressly outside the license — see [`02_constitution/LINEAGE.md`](./02_constitution/LINEAGE.md).
